ملف PAL الحالي

Gambatte
اسم باليت خاص بلعبة

اختَر ملف ROM لقراءة اسمه فقط وتكوين اسم PAL مطابق. الأداة لا تشغّل اللعبة ولا ترفع ملف ROM.

لم يتم اختيار ROM؛ اسم الملف الحالي يُستخدم كما هو.
استخدام الملف في RetroArch Android

1) احفظ الملف. 2) ضعه داخل مجلد palettes الموجود داخل System Directory الخاص بـ RetroArch. 3) من Quick Menu ← Core Options غيّر GB Colorization إلى Custom. 4) أعد تحميل اللعبة.

هذه الأداة لا تحمّل نواة Android الأصلية داخل HTML؛ هي تصنع ملف PAL متوافقًا مع Gambatte، والاختبار الفعلي يتم داخل RetroArch.

اضغط «نسخ محتوى PAL» لنسخ النص، أو «حفظ / تنزيل» لتنزيل ملف بامتداد .pal. بعد الاستيراد يظهر اسم الملف المستورد هنا، وتقدر تعدّله ثم تحفظه بالاسم نفسه أو باسم جديد.

القيمة العشرية هي القيمة المكتوبة في ملف PAL. عدّل قنوات R وG وB مباشرة. زر «عكس» يقلب اللون نفسه، أما «عكس الترتيب» فيبدّل أماكن الألوان: 0↔3 و1↔2.
